## Why this exists

Every previous number in this project was measured against data that
already existed. Even the held-out split in [`validation.py`](../simulation/validation.py)
chose where to cut *after* seeing the whole record — honest, but
retrospective. A forecast issued before resolution is the only test here
that cannot be gamed.

The model's last observation is **2024**, so everything below is out of
sample. Three bands, with different evidential value:

| band | years | status |
|---|---|---|
| resolvable now | 2025 | already elapsed; the model has never seen it |
| resolving | 2026 | partly elapsed at issue |
| prospective | 2027–2030 | genuinely unknown |

## What this model cannot do

**CEED has no ENSO mode.** A very strong El Niño was developing at issue
time and none of its effect is in these numbers. The atmospheric prediction
is therefore expected to run **cold** for 2026–2027. That is recorded here
as a directional prediction rather than offered afterwards as an excuse.
See E9 in [`../legacy/README.md`](../legacy/README.md) for why the
oscillator that would have supplied it was rejected as the wrong shape.

## Falsification criteria

Fixed at issue. Not renegotiable after resolution.

- solar: FALSIFIED if fewer than half of the observed values fall inside their intervals, or if a flat line at the 2024 value scores a better RMSE over 2025-2030.

- magnetic: this forecast is published EXPECTED TO FAIL (out-of-sample R2 = +0.057). The prediction under test is the failure itself. It would be a surprise — and evidence against validation.py — if it verified well.

- atmospheric: this forecast is published EXPECTED TO FAIL (out-of-sample R2 = +0.042). The prediction under test is the failure itself. It would be a surprise — and evidence against validation.py — if it verified well.

- oceanic: this forecast is published EXPECTED TO FAIL (out-of-sample R2 = -2.705). The prediction under test is the failure itself. It would be a surprise — and evidence against validation.py — if it verified well.

- atmospheric, directional: the model has no ENSO term while a very strong El Nino is developing, so the 2026 and 2027 predictions are expected to run COLD. If they run WARM instead, the stated reason for the miss is wrong.

- atmospheric, quantitative: the forecast warms at +0.020 K/yr against an observed 2010-2024 trend of +0.036, i.e. 0.56x. Predicted miss is LOW. A high miss falsifies the explanation even if the magnitude happens to fit.

- oceanic, quantitative: the forecast accumulates at +0.185 10^22 J/yr against an observed +0.855, i.e. 0.22x — under-predicting by roughly 4.6x. By 2030 that is a shortfall of about 4.0 10^22 J. This is the specific failure predicted; if oceanic instead tracks observations, validation.py's -2.705 was misleading and needs re-examining.

- whole model: FALSIFIED as a forecasting tool if the mean out-of-sample R2 across subsystems over 2025-2030 is negative, i.e. the ensemble is beaten by persistence.

## How to resolve this

| system | source |
|---|---|
| solar | NOAA SWPC / NRCan Penticton F10.7 annual mean, sfu |
| magnetic | GFZ Potsdam Kp annual mean |
| atmospheric | NASA GISTEMP v4 + 0.19 K offset to 1850-1900 base |
| oceanic | NOAA/NCEI 0-700m OHC anomaly, 10^22 J |

Add the observed values to `OBSERVED_*` in
[`../simulation/unit_bridge.py`](../simulation/unit_bridge.py), then run
`python -m simulation.hindcast --start 2024 --end <year>` to score them.

Whatever the outcome, record it in the falsification log at
[`../legacy/README.md`](../legacy/README.md) — including if the model is
right. A confirmed prediction is a result too.
